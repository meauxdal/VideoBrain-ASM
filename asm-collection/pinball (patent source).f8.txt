;       The coupler of the invention has been programmed, utilizing
;  the specific register implementation described above, to display
;  a "pinball" video game which is externally controlled by a user.
;       The following pages are a program listing of the assembled
;  language for such game.  The microprocessor utilized is the
;  previously mentioned F-8 microprocessor available from Mostek 
;  Corporation and the Fairchild Semiconductor Components Group of 
;  Fairchild Camera and Instrument Corporation.  It was programmed
;  in accordance with the "F-8 User's Guide and Guide to
;  Programming" available in 1976 from Fairchild; and the 1975
;  "F-8 Preliminary Data Book" available from Mostek.  The memory,
;  allocations (in hexadecimal) for the following are:
;
;       ROM "Pinball" Program:    F800-FFAF
;       Display Composer:         0800-OBFF
;       ROM Segment Information:  1000-17FF
;
;       Also, the designation UM1 is used to refer to the display
;  composer; and the designation UM 2 is used to refer collectively
;  to the system controller, the timer and the timing and sync
;  signal generator.

;******************************************       
;*       INITIALIZATION PACKAGE COMMON TO *
;*       ALL PROGRAMS ON THE UM1/UM2      *
;*       SYSTEM.  PROGRAM PACKAGE REQUIRES*
;*       MEMORY LOCATIONS F800 THROUGH    *
;*       F83F--A TOTAL OF 40 BYTES (HEX). *
;******************************************
;*       PROGRAM FUNCTIONS:               *
;*       (1) CLER  LOADS MEMORY LOCATIONS *
;*               800-88F WITH FF.         *
;*       (2) INIT  TRANSFERS XX BYTES OF  *
;*               DATA (XX BEING STORED    *
;*               IN REGISTER 1) STARTING  *
;*               AT LOCATION GIVEN BY     *
;*               REGISTER Q TO LOCATION   *
;*               GIVEN BY REGISTER H.     *
;*       (3) INTS  INITIALIZES ALL UM     *
;*               REGISTERS WITH DATA      *
;*               STARTING IN LOCATION     *
;*               GIVEN BY REGISTER Q.     *
;*       (4) SYNC  SYNCHRONIZES TO LINE   *
;*               NUMBER HEX D.  WILL NOT  *
;*               SYNCHRONIZE TO CORRECT   *
;*               FIELD.                   *
;******************************************
;*       PROGRAM ENTRY POINTS:            *
;*       CLER----$F800                    *
;*       INTS----$F817                    *
;*       INIT----$F80D                    *
;*       SYNC----$F837                    *
;******************************************
        ORG     $F800

CLER    DCI     $800
        LI      $90
        LR      1,A     ; SET COUNTER
        LI      $FF     
CLR1    ST              ; STORE FF
        DS      1       ; DECREMENT COUNTER
        BNZ     CLR1    ; DONE?
        POP             ; YES--RETURN
;******************************************
INIT    LR      DC,Q    ; GET ORIGIN ADDRESS
        LM              ; GET CONTENTS SAME
        LR      Q,DC    ; SAVE NEW ORIGIN
        LR      DC,H    ; GET DEST. ADDRESS
        ST              ; TRANSFER BYTE
        LR      H,DC    ; SAVE NEW DEST.
        DS      1       ; DECREMENT COUNTER
        BNZ     INIT    ; TRANSFER DONE?
        POP             ; YES--RETURN
;******************************************        
INTS    LR      K,P     ; SAVE RETURN ADDR.
        PI      CLER    ; CLEAR REGISTERS
        LI      $60     ; SET TRANSFER COUNT
        LR      1,A     ; AND STORE IN 1
        DCI     $800
        LR      H,DC    ; SET DEST. ADDRESS
        PI      INIT
        LI      $10
        ADC
        LR      H,DC    ; Y L.O.A. LOAD
        LR      1,A     ; TRANSFER COUNT
        PI      INIT
        DCI     $8F0
        LR      H,DC
        LIS     $7
        LR      1,A
        PI      INIT    ; SET SELECTED REGS.
        PK              ; AND RETURN
;******************************************
SYNC    DCI     $8FB
        LM              ; GET LINE NUMBER
        CI      $D
        BNZ     SYNC    ; ARE WE AT LINE D?
        POP             ; YES--RETURN
;******************************************
